面對面傳送

兩台裝置連上同一個 Wi-Fi 或手機熱點，互掃 QR code 配對之後，直接傳暫存區的檔案，不經過任何伺服器。

使用方式

  1. 兩台裝置連上同一個 Wi-Fi 或手機熱點，送出的一端先按「選擇檔案」，把檔案放進暫存區。
  2. 送出的一端按「送出暫存區的檔案」，接收的一端按「接收檔案」，互掃 QR code 配對。
  3. 核對兩邊的確認碼相同，接收的一端按「接收」，檔案放進暫存區。

安全地傳送

加密之後再傳送，只有對方能打開。

  • 加密
    只給對方看的檔案
  • 解密
    打開收到的 .age 檔案
  • 加密文字
    只給對方看的一段訊息
  • 遠端傳送
    把檔案交給不在身邊的人
  • age 金鑰產生器
    讓別人加密檔案給你
  • 密語與密碼產生器
    好記又夠強的密語
  • QR code 產生器
    網址、Wi-Fi 密碼、聯絡資料
