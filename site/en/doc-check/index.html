Check before opening

Before opening a Word file or PDF you received, see whether it reaches out to the internet or runs code.

How to use it

  1. Choose a Word, Excel, PowerPoint, LibreOffice document or PDF you received.
  2. The screen lists the outside addresses, macros and JavaScript the file would load or run when opened, plus the links inside it.
  3. If a PDF looks suspicious, press “Make a safe PDF” to turn every page into an image, and open that version instead.
