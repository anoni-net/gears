文档打开前检查

打开收到的 Word、PDF 之前，先看看会不会连到外面、执行程序。

使用方法

  1. 选择收到的 Word、Excel、PowerPoint、LibreOffice 文档或 PDF。
  2. 画面列出打开时会连到的外部网址、宏与 JavaScript，以及文档里的链接。
  3. PDF 有疑虑时按「转成安全的 PDF」，每一页转成图片，之后打开转好的版本。

检查收到的

收到文件、邮件或链接时，先确认来源是否可信。

  • 查证文件
    收到的照片与文档
  • 视频的关键帧
    找出视频原本的出处
  • 邮件检查
    可疑的通知邮件
  • 下载的软件验证
    下载的 Tor Browser 与 Tails
  • 网址检查
    可疑的链接
  • QR code 与条码读取
    扫到的链接、付款码与票券
