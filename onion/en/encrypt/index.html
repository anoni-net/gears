Encrypt

Encrypt files with a passphrase or the recipient's public key, so only they can open them.

How to use it

  1. Choose the file to encrypt. Any format works.
  2. Set a passphrase or paste the recipient's age public key, then press “Encrypt”.
  3. Download the .age file and send it. Share the passphrase through a different channel. A ready-made note for the recipient appears on screen to send along with it.

Send it safely

Encrypt before sending, so only the recipient can open it.
