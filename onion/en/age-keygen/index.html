age key generator

Generate a public and private key. Files encrypted with your public key can only be opened by you.

How to use it

  1. Press “Generate a key pair”.
  2. Give the public key to people who want to send you files. They encrypt with it.
  3. Press “Download key file” to keep the private key, which decrypts the files you receive.

Send it safely

Encrypt before sending, so only the recipient can open it.
