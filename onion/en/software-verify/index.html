Verify downloaded software

Check that a Tor Browser or Tails download is officially signed and unchanged.

How to use it

  1. Download the installer from the official site, along with the signature file next to the download link (.asc or .sig, which the project uses to prove the file hasn't been changed).
  2. Press “Choose the downloaded file” and “Choose the signature”, or pick both at once.
  3. The result says whether the signature is good. Don’t install a file that doesn’t match.
